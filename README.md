# Lydbar - DJ & Musikk

En moderne nettside for Lydbar, som tilbyr DJ-kurs og musikk-opplæring.

## Innhold

- **Privatkurs**: En-til-en DJ-opplæring
- **Gruppekurs**: DJ-ing i gruppe
- **Blog**: Tips og guides for DJ-ing
- **Booking-system**: Bestill time eller plass på kurs
- **Kontaktskjema**: Kontakt oss direkte

## Features

- Responsiv design (mobil, tablet, desktop)
- Booking-modal med kalender
- Stripe-integrasjon for betaling
- Supabase-integrering (bookinger & autentisering)
- Email-notifikasjoner via EmailJS

## Bruk

1. Åpne `index.html` i en nettleser
2. Naviger mellom seksjonene
3. Klikk "Finn tid" for privattkurs eller "Reservér plass" for gruppekurs
4. Fyll ut skjemaet og gjennomfør booking

## Teknologi

- HTML5
- CSS3
- JavaScript (vanilla)
- Supabase (database & auth)
- Stripe (payments)
- EmailJS (emails)
